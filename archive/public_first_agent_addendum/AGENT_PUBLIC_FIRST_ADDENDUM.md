# 给 AI agent 的“公开数据先行”补充指令

本文件是对旧启动包 G0–G2 顺序的**建议调整**，不是作业授权。研究负责人批准后，允许在新增 DFT 为零的情况下先进行公开数据模块原型；所有真正有效的目录权限、预算和审批仍以负责人签署的资源文件为准。本文件不改写上传的 resources.yaml。

## 当前事实与边界

上传配置记录了一个未提交修改的仓库，冻结 commit 为空；半经验和参考计算器尚无已验证路径；全部试算预算为零；作业提交关闭；允许写入的只有 starter 目录。远端 n2 的程序安装、实际显存、磁盘、队列可用性没有在本次回复中实测。不要据此提交任务、自动填负责人姓名、伪造运行日志或宣称已有冻结版本。

新增湿实验暂缓，不是项目整体停止条件。公开数据模块验证不要求先聘齐三位人员；参考物理协议与最终机理解释仍需有人承担科学审查责任。

## 执行顺序

1. 复用既有审计，不重复完整数据巡查。根据批准读取范围定位 UniTS、FlowER、Transition1x 资产。先输出一张资产—用途—禁用信息表，并生成代码补丁，保存于允许目录。
2. 将清单分为 `public_data_manifest` 和 `independent_reactant_seed_manifest`。前者可以先生成，但不能代替后者。记录真实版本、记录 ID、分组、几何来源、标签种类、计算层级、单位及许可。不由缺失字段自动推断电荷、自旋、溶剂或家族。
3. 获得 P1 专项预算与写入授权后，运行 xTBloom 的单位/力符号、能量有限差分、CPU–CUDA、独立 xTB/tblite 对照及失败隔离检查。冻结实际安装版本和构建标识。先做分子/气相诊断，不把缺省环境写成“水”。
4. 使用公开 DFT 能量/力，在**同一构型**上补算 GFN2-xTB。保留原子顺序、电荷、自旋、环境和能量定义。训练标量 ΔE，力由其对坐标的负梯度给出；半经验 E/F 作为缓存值或外部调用，不要求对 xTBloom 的力做高阶自动微分。
5. 并行测试守恒事件流、几何诊断及物理引导。缺少事件—几何配对的样本使用标签掩码，不能杜撰联合监督。Transition1x 的路径高点不自动视为频率/IRC 验证 TS。反应端点可作合法监督或明确的端点条件诊断，但不能进入反应物盲提议输入。
6. 限于 P1 证据，报告分组留出上的能量/力校正、结构诊断、约束满足率、失败与成本；不报告新通道的 DFT 成功率或核苷水相机理已确认。
7. 并行准备 CP2K 接口而不提前花费未批准的 DFT 额度。P2a 经批准后首先进行少量 E/F 与协议收敛检查。新候选、新含硫/带电/水环境标签和路径有效性需要新增参考计算；完整 TS/频率/IRC 另设预算。
8. VibeQC 指 `jinzhezenggroup/vibeqc`，不是另一个同名近似项目。所审阅的公共方法表对 DFT 列出 energy，不足以证明所选 DFT 的力已可用。先作为待验证替代候选；未来重新核对冻结版本，做同构型跨代码桥接，不自动替换或混合 CP2K 标签。

## 不可省略的物理边界

- xTBloom 当前文档没有原生隐式溶剂和原生周期执行。有限水簇可以计算，但不等于体相水。需要 ALPB 等时，单列原版 xTB 或其他经验证后端及协议，不要求 agent 顺手重写溶剂引擎。
- xTBloom 的 autograd 支持 dE/dR=-F，不支持力的任意高阶反传。数值 Hessian 约需 6N 次力求值。反应方向估计可评估有限差分 HVP，最终 Hessian 放在小规模验证阶段，不默认每个流步计算全矩阵。
- 普通能量下降不是鞍点引导。物理引导只是候选生成策略，不构成存在正确 TS 的证明。
- 不同泛函、基组、赝势、溶剂与边界条件是不同参考协议。CP2K 和 VibeQC 的切换要保留各自协议 ID；与公开 ωB97X/6-31G(d) 标签不作无标记合并。
- 同一母反应的全部构象、轨迹、增强、SE/DFT 配对和近重复按同组处理。预训练资产也纳入泄漏审查。最终测试由负责人或隔离流程保管；同一个代理换角色不构成独立保管。

## 第一次报告的验收形式

提交可审查补丁或真实新 commit、锁定配置、数据子集清单和哈希、计算器符合性结果、一个小型学习/消融结果、失败清单与累计成本。尚未被授权运行时，仅提交待运行方案与补丁，不虚构任何性能曲线。

先回答：校正势在公开反应区分组留出上是否有效？它对流生成是否有超出统一后处理的增益？然后才扩大到独立反应物状态、竞争事件与水相应用。
