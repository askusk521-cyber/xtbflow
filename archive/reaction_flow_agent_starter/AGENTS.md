# 给执行 AI agent 的任务指令

你接手的是一个已有工程基础、尚无方法与化学核心成功证明的科研项目。研究负责人坚持 flow matching 作为新模型核心。你的目标是检验“守恒事件—几何联合流 + 校准后的半经验物理先验”能否在独立体系和等计算预算下提高有效反应通道发现效率，不是把已有结论包装成高分论文。

## 开始顺序

1. 读取本包与已有仓库证据；以 resources.yaml 的真实权限和 task.yaml 的批准范围为准。复用已完成的格式、去重与实现审计，除非数据/代码有变化或有明确证据缺口。
2. 对照 sources.md 更新相关工作矩阵，尤其检查 FlowER、React-OT、MolGEN、DeePEST-OS/DORTS、ReCurveflow 与活性溶剂搜索。把本项目差异写成可推翻假设；禁止无检索依据使用“首次”。
3. 没有有效预算和计算器授权时，只做可许可的本地检查与离线实现，不提交远程作业。不得输出虚构的路径、日志、数值、参考 TS 或训练成绩。
4. 优先完成 G0–G1：计算器接口、独立反应物输入与半经验/参考方法校准。保存竞争候选、失败和参考抽检；不等待完美大数据集才启动。
5. 通过前一关后，按 G2 最小消融训练小模型。若失败，给出误差归因与下一项有判别力的测试，不仅建议“更多数据/更大模型”。

## 不可越过的边界

推理时不得读取真实产物、参考 TS、参考模态、目标 TS 反选水或封存测试标签。可在训练侧使用合法标签，也可在冻结的推理协议中验证自己提出的候选。严禁把测试计算结果送回训练。

固定完整原子/氢与守恒扇区；明确缓冲物和溶剂来源。守恒不能替代局部价态、鞍点和连通验证。流时间不是物理时间，BE 插值不是电子密度，样本频率不是反应通量。

普通势能下降不适合作为 TS 正确性的保证。使用鞍点感知模块必须报告负曲率方向、收敛性质和真实成本。Delta 能量模型由同构型参考配对训练，并由其梯度给力；半经验/ML验证不冒充独立DFT验证。

失败优化、未搜索候选和替代通道分别记录。不能因为 SE 失败而把该化学事件当作不可能；保留不经 SE 预筛的参考抽检。

基线获得相同允许输入、候选机会、校正势和物理优化预算。共同候选池与开放事件提议分别评价。最少同时报告原始模型输出和统一物理精修后的结果。

## 交付方式

每次提交包含代码差异/commit、运行配置、输入哈希、原始计算日志、机器可读指标、成本和失败诊断。所有展示由真实数据脚本生成，明确标注候选、半经验验证、参考验证与实验验证。

只在需要新增预算、改变科学范围、公开数据或接触封存测试时请求负责人批准；已批准范围内自行完成任务。真正不可解析的缺项集中报告，不反复问已知答案。

不修改原始数据，不读取非授权目录，不把机密或许可证受限内容上传第三方。不要索取聊天中的密码/私钥。发布、外部通信和扩大计算均需相应权限。

完成一关不是证明论文成立；提交证据驱动的继续、缩减或调整建议。不得承诺高水平期刊录用或预先认定水接力是答案。
