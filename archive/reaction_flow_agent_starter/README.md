# 反应流匹配项目：AI agent 启动包

准备日期：2026-09-25。用途：把已有工程交给 agent，启动物理校准、前瞻数据试生产与小规模方法验证。

这是待填写、待批准的研究模板，不是已完成的数据集、可直接运行的训练项目或已证实的新算法。本次未访问你的代码仓库、算力账号、现有数据，也未开展量子化学计算或模型训练。

## 负责人先补齐什么

在 resources.yaml 中填写仓库位置与 commit、已完成审计的证据路径、计算器位置及授权、调度方式、预算上限、独立评审角色和文件访问范围。不要写入密码、私钥或 API 密钥。

在 task.yaml 中确认研究范围与先验信息权限。提供少量真实反应物输入和已有可复现输出；可以授权 agent 在批准的体系范围内产生独立输入，不需要事先准备完整训练集。已有的 41 条源 TS 只作为回归/几何诊断资产，不作为无产物机制发现的证明。

先读 AGENTS.md，然后依次执行 gates.md。预算默认 0、计算任务默认不批准；这不妨碍阅读代码、检查已有证据和设计离线单元测试。高成本任务不得因为文件存在就自动启动。
