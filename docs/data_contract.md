# 数据合同

## 1. 首先冻结输入，再进行发现

独立生成并保存反应物微观态、构象、组分相对位置与溶剂快照，写入输入哈希和生成方法。候选水来自输入侧；不能以参考 TS 的反应模态筛掉其他水。参考 TS 反向 IRC 的端点可用于验证和监督，但不能冒充独立制备的盲预测输入。

数据关系是：母体系 → 独立反应前状态 → 多个尝试 → 验证通道 → 一个或多个几何/路径。一个事件可有多个 TS；一条失败初始化不否定该事件。没有足够信息的初始记录不得伪装为完整监督标签。

## 2. 每次尝试必须记录

输入 ID 与哈希；母体系和家族 ID；提议方法及版本；随机种子；允许的反应意图；原计划事件；活性分子选择；初猜几何；每一级计算方法、基组、溶剂、SCF/优化设置；单位；总电荷和自旋；计算状态与原始日志；能量、力及可获得的曲率；实际端点、实际事件、手性；成本、重试次数与失败原因。

能量基准、计量组成、质子数、显式水数与标准态必须可追溯。对于不同质子数/组分的自由能比较，另附热力学循环或化学势协议；不得直接比较不同组成簇的裸总能量。

## 3. 证据状态

- unattempted：没有搜索，不是负样本。
- attempted_unresolved：失败、超时、SCF 不收敛或预算耗尽；仅描述尝试。
- valid_alternative：找到有效的另一通道，保留实际事件。
- se_validated：只在指定半经验方法上通过验证，不称为 DFT 真值。
- reference_single_point_labeled：有参考能量/力，但未证明参考势能面存在正确 TS。
- reference_ts_connected：参考 TS 优化、反应相关的单一负曲率模式、双向 IRC 与端点检查通过。
- solution_prediction_validated：另有微观态/构象统计与动力学或实验扰动验证。

不同证据等级不强行排序为单一分数。频率阈值、刚体/冻结自由度处理及端点判定必须先在协议中固定。

## 4. 多保真配对

同一个 X、原子顺序、总电荷、自旋及明确匹配的环境定义，分别计算 U_SE(X)、F_SE(X)、U_ref(X)、F_ref(X)。

DeltaU(X) = U_ref(X) - U_SE(X)
DeltaF(X) = F_ref(X) - F_SE(X)

标量能量校正的力由负梯度获得，不单独拼接一个无保守性保证的力头。不能拿参考 TS 与另外优化的半经验极小点之差充当同构型 Delta 标签。

配对点覆盖反应物、过渡区、TS 附近的正交扰动、竞争路径与模型难点；不能只有几乎零力的优化驻点。按方法来源保留标签，不把 SE 采样位置当成参考势能面路径真值。

## 5. 避免半经验方法的盲区变成数据集盲区

预留不经半经验成功筛选的参考计算抽检，包括低模型分数、SE 失败和分歧大的候选。若正式总体排除某类体系，说明排除规则与覆盖率；不能只报告 SE 易成功子集而声称普遍可靠。

主动学习只用于训练/开发集合。测试输入、标签和开发反馈分离；封存评估可以调用固定推理协议允许的计算器，但输出不能用于模型/阈值更新。

## 6. 划分与许可

同一母体系的构象、溶剂快照、正逆过程、邻近轨迹帧和多保真配对点必须在同组。分别定义骨架、反应核心/家族、微观态与溶剂泛化。预训练也必须审计；无法排除污染时明确报告，不称严格家族外推。

第三方数据来源、许可证、允许再分发的字段、代码/模型权重权限必须分别登记。原始/中间/派生文件记录哈希；公开许可未确认时只能内部使用，不自动打包发布。

## 7. 展示

样本浏览器展示反应前状态、事件、猜测/SE验证/参考验证三个几何层级、曲率、IRC、计算方法、失败原因和成本。抽样规则预先固定，保留成功、边界与失败案例。生成过程动画和物理 IRC 动画必须使用不同标签。
