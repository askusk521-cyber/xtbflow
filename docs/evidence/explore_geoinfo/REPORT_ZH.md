# 几何信息检查：信息上界与时间窗口（探索性）

本报告全部结果为探索性，只用 V1a 开发集（62 个母体、21 个分子式组），不改变 V1a 的 `GO_V1b`，也不构成 V1b 的任何决策。检查 A 显示：配对训练下，看到真实 TS 几何的势垒头在同母体通道排序上与只看事件的头没有可检出的差别（Spearman 差 +0.027，95% 区间 [−0.111, +0.165]）。检查 B 显示：事件的中位定型时刻是 t=0.50；预测终点上的 GFN2-xTB 能量要到 t≈0.7 才变得有信息，此后仍未定型的轨迹只占 14.5%，按预先写定的规则判为 `NO_USABLE_WINDOW`。

问题来源：方向讨论中提出的两个快速检查——"几何里有什么信息是事件里没有的"（信息上界），以及"事件定型是否早于几何变得有物理意义"（时间窗口）。配置 `configs/explore/geometry_information.json`（geoinfo-1.1）在读取开发数据前提交；运行代码 `68f5733`，n2 上从该 SHA 的干净克隆运行。

## 检查 B：事件何时定型，几何何时有物理意义

V1a 冻结的联合生成器（3 个训练 seed），同步路径 50 步、无引导，每个开发母体每个 seed 32 条，共 5,952 条轨迹；4,936 条最终解码为合法事件（1,460 条代理命中、876 条已知事件几何未命中、2,600 条目录外事件、1,016 条非法）。

"定型时刻"是逐步解码预测终点 b̂₁ 后，此后每一步都等于最终事件的最早时刻。xTB 信号是预测终点 x̂₁(t) 上的 GFN2-xTB 能量；h_X 信号是 B1 引导实际使用的量（当前状态上的冻结 h_X 均值）。ρ 为同母体内、对最终事件目录势垒的 Spearman 相关（跨 seed 合并），62 个母体平均。

| t | 已定型比例 | h_X 的 ρ | xTB(x̂₁) 的 ρ | xTB(x̂₁) 与最终 xTB 的 ρ |
|---:|---:|---:|---:|---:|
| 0.0 | 0.001 | 0.146 | −0.015 | 0.024 |
| 0.2 | 0.034 | 0.187 | −0.019 | 0.099 |
| 0.3 | 0.131 | 0.241 | −0.025 | 0.165 |
| 0.4 | 0.320 | 0.292 | 0.032 | 0.273 |
| 0.5 | 0.537 | 0.367 | 0.115 | 0.433 |
| 0.6 | 0.727 | 0.446 | 0.221 | 0.586 |
| 0.7 | 0.855 | 0.543 | 0.330 | 0.729 |
| 0.8 | 0.920 | 0.605 | 0.440 | 0.869 |
| 1.0 | 1.000 | 0.653 [0.561, 0.745] | 0.512 [0.394, 0.630] | 1 |

- 定型中位数 t=0.50（四分位 0.38–0.62）；各母体在 t=0.5 前定型的比例为 0.527 [0.488, 0.567]。
- 按预写规则（达到 t=1 相关值一半的最早时刻为 t_geo）：xTB 的 t_geo=0.7，此后仍未定型的轨迹占 14.5%，读法 `NO_USABLE_WINDOW`；h_X 的 t_geo=0.5，窗口比例 46.3%，读法 `WINDOW_EXISTS`。
- 敏感性（按"哪些键在变"定义定型）：中位 0.48，窗口比例 xTB 13.9%、h_X 44.4%，结论不变。
- 自我纠错（E4 所用的量）：39.4% 的合法终点轨迹在 t=0.5 还解码不出合法事件；能解码的轨迹中 9.6% 之后改变了事件，改变者命中最佳事件的比例（7.3%）低于未改变者（18.6%），晚期改变不像是纠错。

h_X 在 t=0 就有 0.15 的相关。t=0 的状态只含反应物和初始噪声，而确定性积分的终点由初始噪声决定，所以 h_X 的相关中有一部分来自它对含噪事件状态 b_t 的读取，不能全部算作几何信息；这项检查无法把两者分开。

## 解读

1. **学习型几何引导（E2a 路线）缺少信息基础。** 即使给真实 TS 几何，配对训练下的几何增量也只有 +0.027（区间上限 +0.165），top-1 还更差。结合任务 R 中 B1−B0 的单候选增益约为 0，"生成中途的模糊几何比事件更会选通道"这一前提没有得到支持。区间较宽，不能排除中等大小的增益，但已不支持把 E2a 作为打头的实验。
2. **真实物理在好几何上是有信息的，但在当前生成过程中来得太晚。** xTB 在真实 TS 几何上的排序是所有打分器中最高的（0.749，与 E_frozen 之差区间含 0）。但预测终点上的 xTB 能量在 t≈0.5 前基本无信息（ρ≤0.12），等它变得有用时，85% 的事件已经定型。按当前同步时钟，真实物理引导几乎没有可作用的窗口。
3. **事件并非早早定型。** 约一半轨迹在 t=0.5 时仍未定型，所以"窗口"在事件一侧是存在的，缺的是几何一侧的成熟度。联合生成器训练时使用独立的 t_b、t_x，因此"几何先行"的时钟（让 x 比 b 更早成熟）是一个可以直接测的设计变量，不需要重训。
4. **E4 自我纠错没有支持。** 晚期改变事件的轨迹命中最佳事件的比例更低。

## 偏差、限制与披露

- 冻结配置后、正式运行前，3 个母体 × 4 条的 CPU 冒烟显示预测终点在 t≈0.4–0.5 前多数无法解码，于是增加了"键变化集合"的定型敏感性定义，并把自我纠错限定在 t=0.5 可解码的轨迹（geoinfo-1.1，配置内记录）；主定义和读法未改。
- 开发集曾参与 V1a 的调参；本检查只用于方向判断，不作确认性证据。62 个母体的区间半宽约 0.12–0.19。
- 每个通道恰有一条参考记录，因此"min/mean 汇总"与"记录级"敏感性与主分析完全相同。
- oracle 的区间和"xTB 与最终 xTB"在 t=1 处为退化方差（全为 1），按约定报告为 [−1, 1]；后者的 t_geo 规则因此不适用，只作描述曲线。
- x̂₁ 中有原子间距 < 0.5 Å 的几何不算 xTB（t=0.1 时最多 403/5,952 条，t≥0.7 时 ≤15 条），记为缺失。
- xTB 用的是 DFT 几何上的单点，不是 xTB 优化后的 TS；目录势垒本身是 T1x 的 CINEB 参考，未经频率/IRC 认证。
