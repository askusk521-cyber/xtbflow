# 鞍点感知物理引导（pg-1，探索性）

本报告全部结果为探索性，只用 V1a 开发集（62 个母体、21 个分子式组），V1b 暂缓，不改变任何既有决策。在 `geometry_lead3` 时钟上用 GFN2-xTB 力做鞍点感知推动，确实改写了 12–27% 轨迹的最终事件，但改写只微弱地偏向低势垒通道：事件效用相对不推 +0.003 [+0.000, +0.006]（α=0.3）和 +0.008 [−0.001, +0.017]（α=1.0），按预写规则分别为 `SHIFT_NOT_SPECIFIC` 和 `NO_DETECTABLE_SHIFT`。鞍点感知的必要性得到支持：同样幅度的朴素能量下降让合法率掉 11.2 个百分点，鞍点形式不掉。

设计见 `docs/explore/PHYSICS_GUIDANCE_DESIGN_ZH.md`；配置 `configs/explore/physics_guidance.json`（pg-1）和代码 `1efad90` 均在运行前提交，n2 上从该 SHA 的干净克隆运行。

## 设置

- 时钟 `geometry_lead3`（t_b = s³，t_x = s），窗口 t_x ∈ [0.5, 0.95)，每条轨迹约 23 步施加推动。
- 每步在预测终点 x̂₁ 上算 xTB 力 F；鞍点方向 (I − 2uuᵀ)F，u 来自预测键级变化；单位 RMS 步长 α·Δt_x。
- 3 个训练 seed × 每母体 32 条 × 62 母体 = 5,952 条轨迹/臂；七个臂共用初始噪声，逐条配对。
- **复现**：不推的臂在新的记录式积分下与 geolead-1 的 `geometry_lead3` 结果逐条一致（最终事件、代理状态、定型步 100%）。

诊断：两档 α 平均各施加 22.9 步，累计 RMS 位移 0.137 和 0.458 Å，物理臂与随机臂一致；xTB 失败（不含原子过近）在 5,952×23 次调用中 ≤ 9 次；鞍点臂的 |cos(u, F)| 平均 0.32–0.34，即反射确实改变了相当一部分力方向。

## 解读

1. **几何推动能改写事件，耦合通道是真实且很强的。** 只推几何，0.46 Å 的累计位移就改变了约 27–33% 的最终事件，三种方向都如此。"几何信号改不动事件"这一风险在几何先行时钟上没有出现。
2. **但真实物理的方向性很弱。** 鞍点推动带来的事件效用增益点估计为 +0.003 和 +0.008（相对基线约 +2% 和 +6%），区间都贴近或包含 0。在 α=1.0 时它显著好于同幅度的随机推动（+0.014），主要是因为随机推动本身有害（−0.006），而鞍点推动没有。
3. **鞍点感知是必要的。** 朴素下降在 α=1.0 时让合法率掉 11.2 个百分点，符合"推向极小点"的预期；它在幸存轨迹上势垒更低（−1.3 kcal/mol），这是选择效应而不是改进。鞍点形式不损失合法率。
4. **剂量—响应向上。** α 从 0.3 到 1.0，鞍点臂的效用增益从 +0.003 升到 +0.008，合法率不降，说明还有加大推动的余地；但这已是在开发集上的结果，再调 α 就是在开发集上调参。

## 偏差、限制与披露

- 时钟选择（lead3）用过开发集结果；α 两档预先写定，没有按结果挑选。
- u 来自模型当前的事件预测，可能把轨迹锁在当前通道附近，限制了"换到更低通道"的能力；曲率估计的 u（二聚体/HVP）没有测。
- xTB 与 ωB97X 的势垒排序并不一致；效用仍按 T1x 目录势垒计。
- 只回答"能不能把事件推向低势垒"，没有计成本，也没有和 V1a 的预算曲线对比。
- 62 个母体，效用差的区间半宽约 0.003–0.009。
