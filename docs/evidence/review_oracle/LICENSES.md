# Oracle availability and licensing

- **GFN1-xTB / GFN2-xTB**: existing read-only `xtbflow` environment, tblite 0.7.0 (LGPL-3.0); no installation or license acceptance. Neutral singlet, 300 K electronic temperature, accuracy 1.0, maximum 250 iterations; Hartree converted with 627.509474 kcal/mol.
- **g-xTB**: public https://github.com/grimme-lab/g-xtb, GPL-3.0, release v2.0.1, modified xtb 6.7.1 Linux binary `xtb-6.7.1-gxtb-140526-linux-x86_64.tar.xz`. Archive SHA256 `cdfb81164f8d3300fc451dbbf2414528b533e71f7a30ec824b564cd30d6d9e5c`, matched the publisher checksum. Size 39,688,508 bytes. Command `xtb input.xyz --gxtb --chrg 0 --acc 1.0`, isolated temporary directory. No `--uhf 0`, since this particular binary would enable unrestricted calculations even with zero unpaired electrons; default is the required restricted neutral singlet. No terms accepted or website login.
- **AIMNet2 / AIMNet2-rxn**: `aimnet==0.2.0`, public https://github.com/isayevlab/aimnetcentral, MIT. New private environment with Python 3.11 and torch 2.10.0+cpu; no GPU computation. Official member-zero models obtained from `https://storage.googleapis.com/aimnetcentral/aimnet2v2/`. General model path `AIMNet2/aimnet2_wb97m_d3_0.pt`, SHA256 `f0f7c054539ad3261bd36f9b11c56d12f87cb723e25bea7521755bbd3ec24e28`; reaction model path `AIMNet2rxn/aimnet2_rxn_0.pt`, SHA256 `ce8bc2a4cc6fcb5ebaa1bc8897fcd75104e5a00fe86e9d5fc6a020d572174894`. Both hashes match the official model registry. API returns eV, converted with 23.060547830619 kcal/mol. Installed calculator `_apply_family_defaults` recognizes reaction-family metadata and adds the prescribed post-hoc D3 correction, despite the raw model declaring no embedded dispersion. Each family is compared only through same-composition energy differences; absolute energy scales are not mixed. No terms accepted or gated download.
- **UMA / MACE-OMol25**: `UNAVAILABLE_GATED_LICENSE`; excluded according to the handoff. No license acceptance, login or gated model download attempted. The owner's instruction to decide autonomously is not treated as acceptance of third-party terms.

All individual downloads were below 1 GB. n2 had no `curl` executable; initial curl-based availability checks therefore were not evidence of network unavailability. Public model assets were downloaded locally and copied as external assets (not code), while code synchronization used Git exclusively. No oracle was selected based on its evaluation performance.
