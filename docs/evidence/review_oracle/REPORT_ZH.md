## 复现与方法边界

GFN2 的 558 条真实几何势垒逐条误差为 0；ρ=0.7491015704725383，区间 [0.6524459560799384, 0.8457571848651383]，全部符合交接要求。T2b 按候选标识哈希排序，每个母体最多八条，共 2644 条。所有方法使用同一冻结样本；g-xTB 有一个生成几何计算失败，该方法按有限值规则统计，保留失败记录。

真实几何先以通道最小预测值聚合；生成几何按至少四个有限候选、至少两个目标值计算。区间直接复用 split_group 分子式聚类 t 方法，配对差仅用两侧均可估计的母体。MAE、偏差、top-1 和一致对比例见 results.json。

时间是单个 TS/候选能量调用的墙钟，不含已缓存锚定反应物、安装及模型初始化；不同方法分批运行，不能将毫秒级差异解读为严格硬件速度排名。AIMNet2 为 CPU member-zero，不是四成员集成。方法可用性与许可证见 LICENSES.md；UMA 和 MACE-OMol25 因门控许可未运行。
