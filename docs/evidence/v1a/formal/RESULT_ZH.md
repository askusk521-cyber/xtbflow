# V1a 正式冻结前的规划决定（2026-10-07）

开发阶段的功效计划在全部 344 个预留母体、72 个分子式组上给出：

- 直接使用三 seed 开发估计（高斯工作模型）：目标情形联合 GO 约 81.5%（MC 单侧下界约 81.0%）；经验偏态模型约 81.9%。
- 执行者在首次功效扫描前自定的保守余量（SD×1.10、非负 ICC+0.05）下：约 72.8% / 73.6%，因此当时记为 `HOLD_POWER`。

该余量的具体数值不是指导逐字规定的阈值。2026-10-07，项目负责人在看到上述两组数值和风险后，于任何正式集结果产生之前明确选择"按点估计冻结 N=344"（而非保留 `HOLD_POWER`），即按开发估计（无额外余量）的功效计划冻结并执行一次正式筛查。正式集此前未被打开，目标效应（AUC +0.05，M₀、Mᵣ 各 +0.02）与第 10 节闸门均未改变。

必须随结果一起披露的风险：

1. 在保守余量下目标情形的联合功效约 73%，低于 80%；HOLD/NO-GO 的概率相应更高。
2. 开发母体的 M₀、Mᵣ 均值约 +0.013，低于规划目标 +0.02。
3. 开发集只有 21 个分子式组，主差值 SD 与 ICC 的估计不精确。
4. A2 在 seed 0 的几何漂移检查来自事件先行路径的开发流；同步路径的 seed 0 流只含 B1。

按 `v1a_power_plan.py` 中冻结前已写定的规则（按固定 hash 顺序累加完整分子式组，取 GO 的 MC 单侧下界与经验偏态检查都≥80% 的最小前缀），无余量的计划给出 **N=342、G=70**（GO 0.809，`evidence/power_plan_formal.json`）。负责人选择时所称"N=344"是全部预留的近似说法；冻结采用该预设规则的结果，未事后指定 N。未入选的 2 个母体（2 个组）不进入任何训练或评估。
