# 鞍点感知物理引导：设计（pg-1，探索性）

2026-10-08 · 对应配置 `configs/explore/physics_guidance.json` · 运行前提交

## 要回答的问题

在事件尚未定型的时间窗口里，用真实物理（GFN2-xTB）推动几何，能否通过联合模型的耦合把最终事件改写到更低势垒的已知通道？这是"并联独有的卖点"中尚未测过的一环：PR #110 显示学习型几何信号缺少信息基础，PR #111 显示几何先行时钟能以很小代价给物理信号留出约三分之一轨迹的窗口。

## 为什么必须是鞍点感知的

交接第 6 条指出：直接对 E(x̂₁) − E(x_R) 做梯度下降，会把几何推向极小点（反应物或产物盆地），而不是鞍点；按 exp(−βΦ) 重采样也有同样的问题。本设计采用仓库已有的反射形式 G = (I − 2uuᵀ)F（`xtbflow.physics.saddle.saddle_guidance`）：

- 沿反应坐标 u，力被反向，几何被推向该方向上的能量顶端；
- 其余方向保持下降，几何在"分隔面"上滑向能量更低处。

反应物盆地的分隔面上包含所有离开该盆地的一阶鞍点，在分隔面上降能量会流向邻近的、更低的鞍点，因此这一方向在局部带有"偏好低势垒通道"的性质。这是待检验的假设，不是已知结论。朴素下降 G = F 作为负对照一并运行，用来显示鞍点感知是否必要。

## 信号如何构造

1. 每一步在旧状态上读出网络速度，得到预测终点 x̂₁ = x_t + (1 − t_x)v_x 和 b̂₁（与 V1a 的旧状态约定一致）。
2. 在 x̂₁ 上算 GFN2-xTB 梯度，F = −∇E。
3. 反应坐标 u 取自当前预测的键级变化 b̂₁ − b_r：正变化（成键）的原子对沿连线互相靠近，负变化（断键）的互相远离，去质心后归一化。
4. 推动方向只决定方向；步长与 V1a 几何引导一致：单位 RMS 方向 × α·Δt_x，每个原子位移上限 3 倍（`geometry_step`）。只移动几何，事件只通过耦合速度场改变。
5. 只在 x̂₁ 没有小于 0.5 Å 的原子间距、xTB 成功、u 非零时施加；否则该步不推。

时钟用 `geometry_lead3`（t_b = s³，t_x = s），窗口 t_x ∈ [0.5, 0.95)（V1a 冻结的几何引导区间，不在此调）。α 取 0.3（V1a 冻结值）和 1.0，两档都报告，不按结果挑选。

## 臂与对照

| 臂 | 方向 | 作用 |
|---|---|---|
| none | 不推 | 基线；必须复现 geolead-1 的 geometry_lead3 结果 |
| saddle_α | (I − 2uuᵀ)F | 主臂 |
| descent_α | F | 已知有缺陷的形式，负对照 |
| random_α | 每条轨迹一个固定的随机方向 | 同幅度位移的对照，排除"推了就有用" |

所有臂共用初始噪声，按 (母体, 训练 seed, 提议) 一一配对。

## 结果与读法（运行前写定）

主结果是最终候选的事件效用（V1a 代理：已知事件为 max(0, 1 − (Ea − Ea_best)/10)，否则为 0），先在母体内平均，再做分子式聚类 t 区间。对 saddle 和 descent 的每一档 α：

- `PHYSICS_REWRITES_TOWARD_LOW_BARRIER`：相对 none 和相对同幅度 random 的下界都 > 0；
- `SHIFT_NOT_SPECIFIC`：相对 none 下界 > 0，但相对 random 区间触及 0；
- `NO_DETECTABLE_SHIFT`：相对 none 区间含 0；
- `PHYSICS_HURTS`：相对 none 上界 < 0。

另报：最佳事件、最佳参考、合法率、代理命中、最终事件被改变的比例、两臂都落在已知事件时的目录势垒变化，以及 |cos(u, F)|（鞍点反射实际改变了多少方向）。

## 已知风险

- u 来自模型自己当前的事件预测，可能把轨迹锁在当前通道上，削弱"换通道"的能力；若结果显示事件几乎不变，应先考虑这一点，再考虑曲率估计的 u（二聚体/HVP），后者成本高一个数量级。
- xTB 与 ωB97X 的势垒排序不同；PR #110 中 xTB 在真实 TS 上的同母体排序相关为 0.75。
- 只有开发集，且时钟选择用过开发集结果；任何正向结果都需要在新留出集上重测。
- 不计成本：本轮回答"能不能改写事件"，不回答"同成本下是否更划算"。
