# xtbflow 课题方向规划：以并联事件—几何生成为核心

## 结论先行

**建议：课题主张从“并联生成得更准”改为“并联让生成过程能被物理信号实时改写”，用 4 周的优势定位实验找出最强的一条。** 今天完成的 M0 给出 NO-GO：在无引导、同步时间、高斯松弛事件的配置下，并联与串联打平，Δ = −0.015，95% CI \[−0.067, 0.033\]。这与理论一致：两种分解表达同一个联合分布，无引导采样本来就难拉开差距。

并联真正独有的是推理期的操作能力。生成过程中，作用在几何上的信号会改变尚未确定的离散事件；串联在事件解码后就无法回头。

- **最大创新点候选（主假设 H1）：物理在环的反应通道选择。** 用势垒信号引导正在形成的 TS 几何，让模型优先生成低势垒的反应事件，并在相同物理调用预算下胜过“串联先定事件、再评估”的做法。目前未检索到同时满足单端、显式守恒事件、单一并联流、物理信号改写事件的已发表工作。
- **备选卖点：** H2 双向条件（几何线索推断事件，部分事件补全几何，一个模型完成）；H3 复杂反应上的生成中纠错；H4 同等命中下更少的网络调用。
- **两个关键改动：** 训练时两模态独立抽时间，让串联成为并联模型里的一条采样路径，从而在同一组参数下比较耦合方式；评测从 35 个测试母体改为按分子式分组的 5 折交叉验证（约 1,075 个母体）。
- **成本：** M0 单次 60k 步训练约 0.45 GPU 小时，整轮正式实验 5.6 GPU 小时。四周实验估计不超过 100 GPU 小时，瓶颈是评测设计和统计功效，不是算力。
- **节点：** 10/21 定默认耦合路径；10/28 判 H1 的无成本版本是否成立；11/11 选定论文主卖点；12 月中旬出预印本初稿。

工作题目：《Coupled event–geometry flows let physics choose the reaction channel》（单端反应发现中，物理信号经由并联生成改写反应通道）。

1. **并联选对事件的能力不差，差在几何精度。** 事件召回略高；严格阈值下（δ ≤ 0.4 Å）落后，宽阈值下（δ ≥ 0.7 Å）略领先但不显著。可检验的解释：同步时间下，几何在事件还模糊时就开始成形，而高斯松弛的事件矩阵要到 t 接近 1 才变清晰。

## 并联的优势应该在哪里找

**不要在“无引导采样质量”上找并联的优势，要在“生成过程中能对它做什么”上找。** 若两个网络都完美，串联 p(E | R)·p(X | E, R) 与并联 p(E, X | R) 是同一个分布。无引导采样的差异只来自有限容量的归纳偏置和曝光偏差（串联的几何网络训练时只见过真实事件），量级小，M0 正好印证了这一点。

结构上，只有四件事并联能做而串联做不到：

| 操作 | 并联 | 串联 | 对应实验 |
| --- | --- | --- | --- |
| 跨模态引导：几何上的信号改写事件 | 事件仍是软状态时，几何信号能改变它最终落在哪个通道 | 事件先定；几何信号只能事后重排或丢弃 | E2（主） |
| 双向条件：用几何线索推断事件 | 冻结任一模态的一部分，补全另一模态 | 只有“事件 → 几何”一个方向 | E3 |
| 生成中纠错 | 几何与事件不一致时，事件还能被拉回 | 解码错了就无法回头 | E4 |
| 中途剪枝 | 轨迹中途就能用几何估势垒，提前淘汰高势垒粒子 | 必须先生成完整 TS 才能评估 | E2、E5 |

这张表也是论文的论证骨架：每个卖点都对应一个“串联按构造做不到”的操作，审稿人无法用“串联也能表示联合分布”来反驳。

&#91;embedded content: 串联与并联中物理信号进入的位置\]

串联里，物理信号只能作用在事件已定的候选上；并联里，它在事件仍是软状态时作用于几何，再经耦合改变事件落在哪个通道。

## 可修改的设计空间

**保留“事件与几何在同一条流里共同演化”这一机制，其余都作为实验变量。** 每项改动只回答一个问题：它是否放大了上一节的四种操作能力。

| 维度 | M0 的选择 | 候选改动 | 为什么值得试 |
| --- | --- | --- | --- |
| 时间耦合 | 两模态共用一个 t，同步积分 | 训练时独立抽 (t\_b, t\_x)；推理时沿 (t\_b, t\_x) 平面上的任意路径积分 | 串联成为同一模型里的一条路径，可在同参数下比较耦合方式；能做“事件领先但仍耦合”的路径 |
| 事件表示 | 完整 N×N 键—电子矩阵加高斯噪声，和为零投影 | 离散掩码流：每个原子对的键级在随机时刻定型；只对候选反应中心原子对建模的稀疏表示 | 部分事件提前定型，几何能更早拿到清晰的事件信息；离散状态便于做速率倾斜式引导 |
| 几何表示 | 以加噪反应物为起点的笛卡尔速度 | 先保留笛卡尔；可选加入反应中心的距离先验 | 先排除时间耦合造成的几何精度损失，再考虑换表示 |
| 跨模态信息流 | 共享骨干，边特征含当前 b 与距离 | 加显式一致性特征（由距离估计的键级与事件 Δb 之差）；切断跨模态边做消融 | 量化几何对事件的影响强度，这是 H1 成立的前提 |
| 物理组件 | M0 未使用 | 学习的势垒头：从 (x\_t, b\_t, t) 预测 Ea；物理预言机三档：GFN2-xTB、g-xTB、UMA 或 MACE-OMol25 | 势垒头零成本，先回答“几何信号能否改写事件”；预言机回答“在真实物理预算下是否划算” |
| 引导方式 | 无 | 预测终点上的梯度引导；序贯蒙特卡洛（SMC）粒子重采样；后期可做奖励微调 | 梯度引导依赖可微耦合；SMC 不依赖梯度，只需要中途的几何估计 |
| 守恒 | 和为零投影 | 保留；离散表示下改为构造性守恒 | 守恒是相对 FlowER 的三维增量，本轮不作实验变量 |
| 评测协议 | 官方切分，35 个测试母体 | 按分子式分组的 5 折交叉验证，每折 3 个种子；官方测试集只做最终确认 | 区间半宽从约 0.05 降到约 0.01 |

区间半宽的估算：按母体数平方根缩放，√(1075 / 35) ≈ 5.5，0.05 / 5.5 ≈ 0.009。

## 实验一：单模型调度空间实验（E1）

**目的：在同一组参数下比较串联、同步、事件领先等耦合路径，选出默认路径，并让后续所有实验都建在“串联只是其中一条路径”的模型上。** 这排除了 M0 无法排除的容量混淆。

**前置检查 E0（第 1 周，不训练）：**

1. 检查同一母体不同反应的反应物坐标是否相同。若不同，反应物构象可能泄漏通道信息；单端评测改为每个母体固定一个代表构象，否则“通道召回”没有意义。
2. 由缓存能量算每个反应的势垒 Ea = E\_TS − E\_R（eV 换算为 kcal/mol，乘 23.06），标出每个母体的最低势垒已知通道。
3. 生成按分子式分组的 5 折切分文件（训练加验证共 1,075 个母体，官方测试集不参与），提交后不再修改。

**训练。** 每个样本独立抽两个时间，混合四种抽样方式，保证每条推理路径附近都有训练数据：

```latex
(t_b, t_x) \sim 0.4\,\mathrm{Diag} + 0.2\,\{t_x = 0,\ t_b \sim U\} + 0.2\,\{t_b = 1,\ t_x \sim U\} + 0.2\,U([0,1]^2)
```

t\_b = 1 时事件输入为真实整数 b\_P，与 M0 几何网络的训练方式一致。骨干改为接收两个时间嵌入，其余沿用 M0 的稳定化骨干和超参。

**推理路径。** 以 s ∈ \[0, 1\] 参数化，每条路径都用 100 次网络调用（与串联的 50 + 50 次相同）：

1. 串联路径：t\_x = 0 时把事件从 0 积分到 1，解码为整数，再积分几何。
2. 同步路径：t\_b = t\_x = s，即 M0 的 B 臂。
3. 事件领先路径：t\_b = s，t\_x = s^γ，γ ∈ {2, 4}。
4. 几何领先路径：t\_x = s，t\_b = s^2。
5. 交替路径：每 10 步交替推进一个模态。

**外部对照：** 每折同时训练 M0 的两网络串联（A）和同步并联（B），确认单模型里的串联路径不比真实串联差超过 0.02。

**指标：** 沿用 M0 的 Hit@32 与 δ 曲线、事件召回、有效率；新增两项：母体内通道召回（找到的已知通道数除以该母体已知通道数），以及事件定型时刻（解码事件此后不再变化的最早时间）。统计用全部折的母体做配对 bootstrap，种子先在母体层面平均。

**预注册判据：**

- 某条耦合路径相对串联路径的 Hit@32 提升，区间下限 > 0：记为“部分耦合优于串联”，选为默认路径。
- 所有路径打平（区间都跨 0 且 |Δ| < 0.01）：记为“并联无代价”，以事件领先路径为默认，后续实验照常进行。
- 若事件领先路径消除了 δ = 0.2 Å 处的几何精度劣势，M0 的劣势就可归因于同步时间，写进论文的机理分析。

**附加臂 E1b：** 在默认路径上把事件表示换成离散掩码流，其余不变，每折 1 个种子，先看趋势。

**成本（估）：** 独立时间模型 90k 步约 0.7 GPU 小时，5 折 × 3 种子约 11 GPU 小时；对照 A、B 共 45 次网络训练约 20 GPU 小时；E1b 约 5 GPU 小时。合计约 36 GPU 小时。

## 实验二至五：优势定位实验组

**E2 是主实验，直接检验最大创新点候选；E3–E5 检验备选卖点，大多复用 E1 的模型和采样结果，几乎不增加训练。**

### E2 物理在环的通道选择（主假设 H1）

**假设：** 在相同预算下，用势垒信号引导正在形成的 TS 几何，会改变并联模型最终生成的事件分布，让低势垒通道被更早、更多地找到。串联即使拿到同样的信号，也只能在事件确定后重排。

**引导方式。** 全部作用在 E1 选出的默认路径和同一个模型上：

```latex
\hat{x}_1 = x_t + (1 - t_x)\, v^x_\theta, \qquad v^x \leftarrow v^x - \lambda(t)\, \nabla_x \Phi(\hat{x}_1, \hat{b}_1)
```

- Φ 是势垒代理。E2a 用学习的势垒头：从 (x\_t, b\_t, t) 预测 Ea，在 T1x 能量上训练，零物理成本。E2b 用物理预言机给出的 E(x̂₁) − E(x\_R)。
- λ(t) 只在 t\_x > 0.4 后打开，因为早期的终点估计不可靠；λ 的大小只在验证折上选。
- SMC 版本：在 t ∈ {0.3, 0.5, 0.7} 按权重 exp(−βΦ) 重采样整组 (b\_t, x\_t) 粒子，不依赖梯度。

**对照臂（同一预算）：**

| 臂 | 信号进入的位置 | 作用 |
| --- | --- | --- |
| G0 无引导加事后重排 | 只在最后 | 生成 N 个候选，对每个完整 TS 算 Φ 后排序；串联能做的上限之一 |
| G1 串联路径加事件级引导 | 只看 (R, E) 的势垒头引导事件 | 最强的串联对照：不靠几何估势垒 |
| G2 串联路径加几何引导 | 事件解码后才引导几何 | 分离出“几何引导本身”的作用 |
| G3 并联加梯度引导 | 生成中引导几何，事件随之改变 | H1 的主臂 |
| G4 并联加 SMC | 生成中途按几何势垒估计重采样 | 不依赖梯度耦合的主臂 |

G1 决定 H1 的成败：如果仅凭二维事件就能估好势垒，并联提供的几何信息就没有增量。H1 要求 G3 或 G4 同时胜过 G0 和 G1。

**指标：**

- 动力学召回：预算 B 内命中母体最低势垒已知通道（事件匹配，且 TS RMSD ≤ 0.5 Å）的母体比例。
- 势垒加权召回：每个已知通道的权重为 exp(−(Ea − Ea,min) / τ)，τ 运行前固定为 5 kcal/mol。
- 成本—召回曲线：横轴为网络调用数（E2a）或预言机梯度调用数（E2b）。
- 事件分布偏移：引导前后各通道出现概率的变化与其 Ea 的 Spearman 相关，应显著为负。

**预注册判据：** 同一预算下，G3 或 G4 的动力学召回同时高于 G0 和 G1，母体配对 bootstrap 区间下限 > 0，且事件分布偏移的相关系数显著为负。E2a 通过后才做 E2b。

**E2b 的物理设置：** 引导与权重用 UMA 或 MACE-OMol25（GPU 上便宜），GFN2-xTB 作低成本档。最终候选做与 T1x 同级别（ωB97x/6-31G(d)）的 DFT 单点，用高斯基组程序（PySCF 或 ORCA）；CP2K 平面波结果不能直接与 T1x 能量比较。引导后出现的、不在 T1x 里的低势垒事件，先用预言机优化加 IRC 确认，再单独报告为“新发现”，不计入动力学召回。

### E3 双向条件（H2）

独立时间训练的模型可以冻结一个模态的已知部分，补全其余部分。四个任务由同一个模型完成：

1. R → (E, TS)：标准单端任务。
2. R + E → TS：给定事件生成 TS，与两网络串联的几何网络比较。
3. R + 几何线索 → E：给出参考 TS 中 2–3 个关键原子间距离（模拟化学家的机理假设），推断事件。串联没有对应方式。
4. R + 部分事件 → 其余事件与 TS：例如指定某个 O–H 键必须断开。

判据：任务 3 中加入几何线索后，事件召回提升的区间下限 > 0。这个能力直接服务后续水相应用，例如指定某个水分子作为质子穿梭体。

### E4 复杂反应上的纠错（H3）

按变化键数（2、3–4、≥ 5）、是否含形式电荷、是否成环分层，比较默认路径与串联路径。另统计自我纠错率：t > 0.5 后解码事件发生改变、且最终正确的轨迹比例（串联按构造为 0）。判据：并联优势随复杂度单调增大，且最复杂一层的区间下限 > 0。复用 E1 的采样结果，几乎零成本。

### E5 计算效率（H4）

比较每 1,000 次网络调用得到的命中数，以及 SMC 中途剪枝节省的预言机调用数。只作辅助结论，不单独作卖点。

## 与竞争工作的差异

**同时满足单端、显式守恒事件、单一并联流、物理信号在生成中改写事件这四点的工作，本次未检索到。** 9 月 25 日出现的 Trèfle 说明“把物理放进生成过程”正在升温，抢发窗口按 6 个月估计。

| 工作 | 输入 | 离散事件 | 事件与 TS 是否在同一条流 | 物理信号 | 与本课题的差别 |
| --- | --- | --- | --- | --- | --- |
| [MolGEN](https://arxiv.org/html/2507.10530v3)（Tuo、Chen、Li） | 仅反应物 | 产物只生成 3D 几何，键事后读出 | 否：产物模型与 TS 模型分别训练、依次使用 | 无；事后取最低能候选作 TS 初猜 | 最接近的对手；结构上正是本课题的串联对照 |
| FlowER（Nature 2025） | 反应物 | 显式键—电子矩阵，守恒 | 不生成 3D | 无 | 只到二维 |
| [ASTRA](https://arxiv.org/abs/2603.25980v1) | 需要已知稳态构型 | 无 | 只生成 TS 几何 | 分数对齐上升结合物理力 | 不在离散反应通道之间做选择 |
| [Trèfle](https://papers.cool/arxiv/2609.32073)（Li 等，2026-09-25） | 反应物加产物 | 无 | 只生成 TS 几何 | 强化学习后训练，把物理条件摊销进单步流模型 | 双端；物理只改几何 |
| React-OT、TS-DFM、RitS、Drift-React | 反应物加产物 | 无 | 只生成 TS | 无或有限 | 双端红海 |
| ByteCRN（arXiv 2606.21002） | 反应物 | 规则枚举 | 否 | 反向验证 | 工业级“枚举加生成”基线 |
| [Multiflow](https://arxiv.org/abs/2402.04997)（ICML 2024，蛋白质） | 不适用 | 离散序列 | 是 | 无 | 技术先例：一个多模态模型完成共设计、折叠与逆折叠；E1 和 E3 的独立时间思路需引用它 |

审稿人最可能的两条质疑，以及实验里预先准备的回答：

- **“引导和 SMC 都是现成技术。”** 贡献不在引导算法本身，而在耦合让连续空间的物理信号作用到离散化学事件上。E2 的 G1、G2 两个对照直接说明，串联拿同样的信号做不到。
- **“为什么不先枚举全部事件，再逐个算 TS？”** 枚举的成本随事件数线性增长。E2b 的成本—召回曲线正面比较这一点，ByteCRN 式枚举作外部基线。

表中未加链接的条目沿用 10 月初评估报告的检索，本次未重新核对。

## 算力预算与对 M0 执行指导的修改

**节点见第 1 节；全部实验估计不超过 100 GPU 小时，DFT 只用于最终候选的单点验证。**

| 实验 | GPU 小时（估） | 其他计算 |
| --- | --- | --- |
| E0 前置检查与切分 | < 1 | 无 |
| E1 加 E1b | 约 36 | 无 |
| E2a 学习势垒引导 | 约 10 | 无 |
| E2b 预言机引导 | 约 10 | GFN2-xTB 在 CPU；约 1,000–2,000 个 ωB97x/6-31G(d) 单点 |
| E3、E4、E5 | 约 5 | 复用 E1 采样 |
| 扩展与外部基线 | 约 30 | MolGEN、FlowER、React-OT 公开代码 |

对 M0 执行指导的修改：

1. **M0 冻结为基线 v0。** 五个分支经负责人批准后合入 main。报告末尾的“转向方向 B”改写为“无引导、同步时间下并联不优于串联”，作为负结果和动机保留。
2. **新代码放在 `src/xtbflow/m1/`，复用 m0 的数据、骨干与评测。** 新增独立时间训练、路径采样器、引导与 SMC、势垒头、交叉验证切分、动力学指标六个模块。
3. **每个实验运行前提交预注册配置。** 内容包括主指标、判据和预算；沿用“结果出来后不改设置”的纪律。
4. **官方 T1x 测试集只在每篇论文定稿前做一次确认性评测。**
5. **继续冻结治理类基础设施，** 时间和算力集中在实验。

方向 B 的水相数据集从 2027 年 1 月开始，作为第二篇的应用与数据贡献；E3 的条件生成可用来指定质子穿梭的水分子。

## 风险与缓解

**最大的风险是“几何信号改不动事件”或“二维事件已足以估势垒”；两者都会在 10/28 的 E2a 中暴露，届时按决策树换主卖点。**

| 风险 | 早期信号 | 缓解 |
| --- | --- | --- |
| 几何信号改不动事件（耦合太弱） | E2a 中 G3 的事件分布偏移接近 0 | 加强跨模态一致性特征；改用不依赖梯度的 SMC（G4）；用 E1b 的离散事件表示让事件更早定型 |
| 二维事件已足以估势垒，几何无增量 | G1 与 G3、G4 打平 | 主卖点转向 E3 双向条件或 E4 纠错 |
| T1x 已知通道不完整 | 引导后大量事件不在数据集里 | 用预言机优化加 IRC 确认，作为新发现单独报告；动力学召回只对已知通道计算 |
| 反应物构象泄漏通道信息 | E0 发现同一母体的反应物构象不同 | 每个母体固定一个代表构象做单端评测 |
| 势垒头或 MLIP 在类 TS 构型上不准 | 势垒头验证集 MAE 超过 5 kcal/mol | 三档预言机并列报告；最终结论只用 DFT 单点 |
| 种子噪声淹没效应 | 种子间 Δ 符号仍不一致 | 每折 3 个种子；判据只看全部母体的配对 bootstrap；必要时用 EMA 集成 |
| 被抢发（单端版 Trèfle 或带引导的 MolGEN） | 出现相关新预印本 | 12 月中旬前挂预印本；差异化放在“物理改写事件”和守恒事件上 |
| 数值不稳定复发 | 非有限损失 | 保留稳定化骨干；每次训练记录梯度范数 |
| 工程膨胀 | 新增治理类代码 | 延续 M0 规则：不新增治理基础设施，算力和时间集中在实验 |
