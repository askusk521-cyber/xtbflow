# 待检验的方法设计：守恒事件—几何流 + 鞍点感知物理先验

这是一份候选研究设计，不是已证明的收敛算法，也不主张各模块本身首创。必须与 sources.md 中的相关工作逐项对照。

## 核心原则

保持 flow matching 为生成模型核心。半经验势用于物理信息、低成本探索与经校准后的鞍点修正，不作为最终真值；参考方法负责校准与独立验证。

联合输出中，事件描述连接端点间的基元变化，几何描述 TS 候选；二者并非同一化学时刻的电子/核快照。FM 时间是生成时间，不能宣称为真实动力学。

## A. 守恒写入变量和参数化

在固定原子集合、完整显式氢和已确认的总电荷/自旋扇区，使用独立的对称键电子变量 b。先明确电子计数约定；不要重复计算对称矩阵中的键电子。

把可线性表示的守恒写成 A b = c。令 Q 为 A 的零空间基：A Q = 0。

    b(tau) = b_R + Q z(tau)
    db/dtau = Q f_theta(...)

只要 A b_R = c，则 A b(tau) = c。初始噪声也在同一零空间；端点离散化/解码后再次验证整数电子计数与价态，并完整报告拒绝率。

严格原子/电子守恒并不保证局部价态或反应物理可行。不要在连续过渡区强行施加稳定分子的整数键级/八隅体规则。完整水与缓冲物候选池必须预先存在；不能在采样中凭空补质子。

## B. 联合事件、几何和参与溶剂

在同一条件输入上学习事件和三维几何的共享表示，几何分支保持旋转/平移等变、同类原子/水置换一致。预测参与水与质子身份；保留必要的旁观环境效应。固定步数检查点互相交换信息，测试是否优于两个独立网络串联。

可以预测无方向符号歧义的反应模式投影 P = u u^T，而不是只回归符号任意的向量 u。最终 u 来自模型候选及局部曲率校正，不得来自测试参考 TS。增加手性保持与反应相关模态检查。

## C. 能量校正与鞍点感知引导

    U_phi(X) = U_SE(X) + DeltaU_phi(X)
    F_phi(X) = -grad U_phi(X)

这是标准 Delta-learning 形式，不应单独作为原创性。若参考环境与 SE 环境不同，明确差值包含的模型差异，不能混称为普适电子相关修正。

普通能量下降会趋向极小点。可检验以下局部鞍点方向：

    G_sad(X, u) = (I - 2 u u^T) F_phi(X),  ||u|| = 1

在一致且去除刚体自由度的坐标度量下，沿 u 反转下坡方向，在正交方向下坡。这个经典鞍点搜索思想只有在方向、曲率和局部势足够正确时才有意义。

作为 FM 的小强度、后期或去噪预测上的修正时，必须固定引导尺度、信赖域、力截断和 SCF 失败策略。不要将强噪声、原子重叠结构直接交给电子结构计算器；不要要求每个 FM 中间态都是驻点。

先把校正实现为无需反传电子结构求解器的采样模块。只有消融证明需要穿过计算器求导，再评估 dxtb 或 Hessian-vector products。有限差分 HVP 的精度和成本都要计入。

后期引导会改变提议分布：除非推导了相应密度变化/校准，不把输出置信度解释为物理概率或无偏 TS 分布。

## 必须区分的两个校正

DeltaU_phi 是半经验势相对于参考势的能量校正；FM 向量场残差是生成流校正。没有额外推导时，后者不能被称为保守力场，也不能从它读出反应势垒。

## 第一批方法对照

强规则+传统初始化；强规则+同一校正势/同一优化器；无约束FM；守恒FM；独立事件/几何FM串联；联合FM；联合FM+普通能量下降；联合FM+鞍点引导；联合FM+校正势引导。

不必一口气全组合训练。先做能够推翻核心假设的顺序消融；控制候选数、训练数据、计算调用和可见输入。若同样的物理优化消除了模型优势，必须如实归因。
