# xtbflow V1a：开发验证与阶段结论

2026-10-07 · 按提供的 V1a v2.1 指导执行

## 结论

**本轮在正式采样前收束为 `HOLD_POWER`：环境和开发验证可用，但现有独立留出规模没有稳健满足目标功效。** 正式集没有生成方法结果，也没有启动 xTB、DFT、OptTS、频率或 IRC。此结论不是对 H1 的正式否定，也不是已完成正式三 seed 筛查后得到的 NO-GO。

需区分两种规划结果：在全部 344 个预留母体、72 个分子式组上，直接使用三 seed 开发估计的联合功效约 **81.5%**；采用保守敏感性参数后约 **72.8%**。经验偏态工作模型的对应结果约为 **81.9%** 和 **73.6%**。因此，点估计能够勉强越过 80%，但结论对合理的 nuisance 参数变化敏感。

保守规划使用“标准差乘 1.10、非负组内相关系数再加 0.05”，并要求模拟功效的 Monte Carlo 单侧下界达到 80%。**这些具体余量是本次执行中的规划选择，不是指导逐字规定的阈值。** 它们在第一次功效扫描、任何正式集结果产生之前写入代码。指导要求的目标效应与正式决策阈值没有修改：AUC 差 +0.05，M₀、Mᵣ 各 +0.02。

## 开发结果的含义

保留用于规划的配置是同步路径，几何引导 αₓ=0.30、区间 [0.50,0.95)，A2 几何晋级点 0.40／0.70；A1 使用 α_b=0.25。它们是开发选择，尚未作为正式筛查配置冻结。

两条路径均在几何时间约 0.50 开始出现较清楚的评分信号；该时刻同步路径的合法事件改变率约 8.4%，事件先行路径约 1.6%，因此选择同步路径继续验证。所选窗口在三 seed 下均有完整配对，评分方向脉冲实际降低了分数；保留所有计划起点，没有根据响应筛掉样本。

seed 0 的开发联合 AUC 如下。数值参与过调参，**不能当作独立确认或正式方法排名**。

| 臂 | 开发联合 AUC |
|---|---:|
| A0 | 0.3528 |
| A1 | 0.1996 |
| A2 | 0.1673 |
| B0，同步 | 0.4597 |
| B1，同步 | 0.2681 |

B1 高于 A2，同时低于 B0；评分与反向传播的成本会减少完成候选数。因此不能把 B1−A2 的开发优势直接归因为几何反馈。指导要求的配对机制检验仍然必要，且本轮没有把开发统计代替正式闸门。

三 seed 平均后的开发母体摘要为：

| 指标 | 开发均值 | 母体标准差 | 估计 ICC，负值按 0 用于规划 |
|---|---:|---:|---:|
| B1−A2 联合 AUC | +0.0860 | 0.2171 | 0.1595 |
| M₀：评分脉冲−不推 | +0.01275 | 0.02991 | 0 |
| Mᵣ：评分脉冲−随机脉冲 | +0.01274 | 0.02811 | 0 |

评分校准有选择偏差：只有末端真正匹配到参考结构的轨迹才有可关联的目录势垒。支持范围内的高覆盖率不等于全部生成状态都物理正确，`PROXY_MATCH` 也不等于经过频率和 IRC 认证的 TS。

## 功效为何未闭环

每个情景模拟 20,000 次；在 72.8% 附近的 Monte Carlo 标准误约 0.31 个百分点。模拟保留实际预留组大小，并检查主比较与机制两对比的相关性、资源停止与机制停止，未用附件里的假设结果充当实验规划。

主比较方差虽因三 seed 平均而降低，组内相关仍会减少有效信息。开发分子式只有 21 组；整组 bootstrap 给出的主差值 SD 的 5%–95% 范围约为 0.180–0.253，ICC 的对应范围约为 −0.149–0.429。这些区间说明 nuisance 估计不够精确，不能把约 81.5% 的单一点估计当作稳健保证。

在已测试的效应网格中，344 个母体对 **AUC +0.06**、机制两项各 +0.02 才达到保守规划下的 80% 联合功效；这只是可识别效应诊断，没有把本轮目标从 +0.05 改成 +0.06。假设新增独立组、维持相近组大小分布，约 453 个母体的一个模拟设计给出约 80.4% 的点功效；它不是实际可用名单，也不是已授权的新研究。

因此，本轮不冻结不足够稳健的正式计划。扩大独立数据或重设 OOF／重训练设计需要新的研究方案；本次没有扩展切分、换正式阈值或打开正式集来决定是否继续。
