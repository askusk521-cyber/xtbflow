# 术语表

## 任务与数据

母体
:   同一个反应物分子。一个母体可以有多条已知反应；所有统计都以母体为单位配对重采样。

单端 / 双端
:   单端只给反应物；双端同时给反应物和产物。本项目是单端设定。

事件
:   产物的键—电子矩阵 \(b_P\)，即哪些键断裂、哪些键形成。

T1x（Transition1x）
:   ωB97X/6-31G(d) 层级的反应路径数据集，本项目全部生成实验的数据来源。

目录 / 已知通道
:   T1x 中某个母体已记录的反应集合。“最低已知参考通道”是其中势垒最低的一条。

## 生成方式与对照臂

串联
:   先由事件网络 g 生成并解码事件，再由几何网络 h 以事件为条件生成 TS 几何。

联合（并联）
:   一个网络 f 在同一条流中同时演化事件与几何，共用时间（M0）或两个时钟（V1a 起）。

A0 / A1 / A2
:   V1a 的串联臂：A0 无引导；A1 用只看事件的势垒头 \(h_E\) 引导事件；A2 为强自适应串联（部分几何展开、排序、几何引导、晋级、重新提议），是主对照。

B0 / B1 / B2
:   V1a 的联合臂：B0 无引导；B1 只对几何施加 \(h_X\) 梯度、事件经耦合继续更新，是主方法；B2 回放 B0 的事件轨迹，用于检查事件反馈。

\(h_E\) / \(h_X\)
:   势垒头：分别从事件、从当前几何预测势垒的轻量网络，在 T1x 训练折内标签上训练。

SMC
:   序贯蒙特卡洛：生成过程中按物理权重重采样整组粒子，不需要梯度。

## 指标与统计

Hit@32
:   M0 主指标：32 个候选中至少一个同时满足事件匹配与 TS RMSD ≤ 0.5 Å 的反应比例，先在母体内平均再对母体平均。

`PROXY_MATCH`
:   V1a 的代理命中：候选与冻结的 T1x 参考记录接近。不是经频率与 IRC 认证的 TS。

AUC（归一化 log-budget）
:   V1a 主终点：在 4、8、16、32、64 五个预算点上，最低已知参考通道联合召回的曲线下面积，按对数预算归一化。

B0 等效候选
:   V1a 的预算单位：按冻结的执行顺序累计网络前向与反向调用，换算为 B0 的候选数。

M₀ / Mᵣ
:   V1a 机制量：评分方向推动相对“不推”与“随机方向”的效用差，两项下界都 > 0 才算机制通过。

κ
:   V1a-R 中每个候选的验证成本，用于计算计入验证成本后的效率前沿。

配对 bootstrap
:   对母体重采样、两臂使用同一组重采样母体，取百分位区间。

## 认证（V1b）

D0–D5
:   V1b 的任务：D0 冻结总体与抽样；D1 开发链实测；D2 参考认证；D3 候选分层审计；D4 V1a 主终点认证；D5 汇总验收。

\(\Delta^{proxy}\) / \(\Delta^{cert}\)
:   代理差值与认证后的差值。V1b 的决策只依赖 \(\Delta^{cert}\)。

IRC
:   内禀反应坐标：从 TS 沿两个方向追踪到两侧极小点的路径，用来确认 TS 连接的反应物和产物。

`STRICT_JOINT_GRAPH_VALID`
:   完整认证链的通过判定：一阶鞍点、IRC 两端身份与事件都与预期一致。

`MINIMUM_PASS`
:   锚点（反应物）优化后确认是极小点。

## 判定状态

`GO` / `NO-GO`
:   M0 闸门的去/留结论。

`GO_V1b`
:   V1a 判定：主比较与机制都支持进入 V1b 认证。

`GENERATION_BEATS_ENUMERATION`、`NO_GAIN_OVER_POSTHOC` 等
:   探索性检查的预写读法，含义见各报告；它们是读法，不是负责人决定。
