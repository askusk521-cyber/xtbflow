# 1 引言

## 1.1 问题：只给反应物的反应通道发现 {#problem}

给定一个反应物分子，它可能沿多条通道反应。**单端**设定只提供反应物（元素、三维坐标和由坐标推断的键—电子矩阵，总电荷 0、自旋单重态），要求模型提出：

1. **化学事件**：产物的键—电子矩阵 \(b_P\)，即哪些键断裂、哪些键形成；
2. **过渡态几何** \(X_{TS}\)：与反应物原子顺序一致的三维坐标。

推理时**不允许**输入产物几何、TS 几何、产物键矩阵、反应模板，也不允许告诉模型该反应物有几条已知反应。这与大多数 TS 生成工作的**双端**设定（给定反应物和产物）不同：双端只需要生成几何，单端还要在多个离散通道中做选择。

数据来自 Transition1x（T1x）[^t1x]：ωB97X/6-31G(d) 层级下由 CINEB 得到的反应路径，每个反应带有反应物、TS 和产物的能量，可以直接算势垒。T1x 的 TS 没有逐条做频率和 IRC 精修，所以它适合做“已知通道目录”的代理参考，严格认证要另做（见 [2.7 节](methods.md#certification)）。

## 1.2 两种生成分解 {#factorizations}

**串联**先生成事件、再以事件为条件生成几何：

\[
p(E, X \mid R) = p(E \mid R)\; p(X \mid E, R).
\]

**联合**（本文也称“并联”）用一个网络在同一条流里同时生成两者，直接建模 \(p(E, X \mid R)\)。

若两种网络都完美，二者表达同一个分布。无引导采样的差异只能来自有限容量下的归纳偏置和曝光偏差（串联的几何网络训练时只见过真实事件），量级预计很小。M0 的结果正好印证了这一点（[3.1 节](results.md#m0)）。

## 1.3 联合独有的四种操作 {#operations}

因此，联合的优势不应在“无引导采样质量”上找，而应在“生成过程中能对它做什么”上找。结构上只有四件事联合能做、串联按构造做不到：

| 操作 | 联合 | 串联 | 对应假设 |
|---|---|---|---|
| 跨模态引导：几何上的信号改写事件 | 事件仍是软状态时，几何信号能改变它最终落在哪个通道 | 事件先定，几何信号只能事后重排或丢弃 | H1（主） |
| 双向条件：用几何线索推断事件 | 冻结任一模态的一部分，补全另一模态 | 只有“事件 → 几何”一个方向 | H2 |
| 生成中纠错 | 几何与事件不一致时，事件还能被拉回 | 解码错了就无法回头 | H3 |
| 中途剪枝 | 轨迹中途就能用几何估势垒，提前淘汰高势垒粒子 | 必须先生成完整 TS 才能评估 | H1、H4 |

这张表也是论证骨架：每个卖点都对应一个“串联按构造做不到”的操作，因此不能用“串联也能表示联合分布”来反驳。

## 1.4 相关工作与定位 {#related}

| 工作 | 输入 | 离散事件 | 事件与 TS 是否在同一条流 | 物理信号 | 与本课题的关系 |
|---|---|---|---|---|---|
| MolGEN[^molgen] | 仅反应物 | 产物只生成三维几何，键事后读出 | 否：产物模型与 TS 模型分别训练、依次使用 | 无；事后取最低能候选 | 最接近的对手，结构上正是串联对照 |
| FlowER[^flower] | 反应物 | 显式键—电子矩阵，守恒 | 不生成三维 | 无 | 只到二维；守恒事件表示的出发点 |
| ASTRA[^astra] | 需要已知稳态构型 | 无 | 只生成 TS | 分数对齐上升结合物理力 | 不在离散通道之间选择 |
| Trèfle[^trefle] | 反应物 + 产物 | 无 | 只生成 TS | 强化学习后训练 | 双端；物理只改几何 |
| React-OT[^reactot] 等 | 反应物 + 产物 | 无 | 只生成 TS | 无或有限 | 双端 |
| ByteCRN[^bytecrn] | 反应物 | 规则枚举 | 否 | 反向验证 | “枚举 + 生成”基线 |
| Multiflow[^multiflow] | 不适用（蛋白质） | 离散序列 | 是 | 无 | 技术先例：一个多模态流同时做共设计、折叠与逆折叠 |

本项目**不是**“第一个流匹配 TS 模型”，也不是“第一个半经验势加机器学习”或“第一个多保真反应数据集”。仓库的定位文档[^sources]把候选差异写为：无真实产物输入下守恒事件与三维几何的联合提议、鞍点感知耦合的可归因增益，以及前瞻性的数据与独立化学验证；这些都必须在匹配资源和输入的对照中成立。表中未加链接的条目沿用 10 月初的检索，详见[参考文献](../references.md)。

## 1.5 研究假设 {#hypotheses}

- **H1 物理在环的通道选择（主假设）**：在相同预算下，用势垒信号引导正在形成的 TS 几何，会改变联合模型最终生成的事件分布，让低势垒通道被更早、更多地找到；串联拿到同样的信号也只能在事件确定后重排。
- **H2 双向条件**：同一模型能用几何线索推断事件，或用部分事件补全几何。
- **H3 生成中纠错**：联合的优势随反应复杂度增大。
- **H4 计算效率**：同等命中下用更少的网络调用。

本报告覆盖的工作主要检验 H1 及其前提（几何信号是否来得及、是否带有方向信息），以及“联合本身是否有代价”的基础问题（M0）。H2、H3 尚未进入实验。

## 1.6 推进方式与证据纪律 {#discipline}

项目按闸门推进，每一步的判据在看到数据前写定：M0（联合 vs 串联基础闸门）→ V1a（已知通道代理筛查）→ V1b（概率抽样 + DFT 通道认证）→ 独立确认。Transition1x 官方测试集已在 M0 用过一次，之后只作为每篇论文定稿前一次的确认性评测。10-08 之后的工作都是探索性的，用来定位问题，不构成确认性证据。
