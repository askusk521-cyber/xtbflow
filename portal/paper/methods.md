## 2.2 表示与守恒 {#representation}

**事件**用完整的 \(N\times N\) 对称键—电子矩阵 \(b\) 表示。总电子数等于全部元素之和（对角元计一次，非对角元计两次），所以电子守恒等价于速度矩阵在有效原子对上的元素和为零；投影有闭式解，即减去有效元素的均值：

\[
\Pi(v) = \Big(v - \tfrac{1}{|\mathcal{A}|}\textstyle\sum_{(i,j)\in\mathcal{A}} v_{ij}\Big)\odot m ,
\]

其中 \(\mathcal{A}\) 是有效原子对，\(m\) 是掩码。

**几何**用笛卡尔坐标，速度等变并去质心。**起点必须带噪声**：单端任务里同一反应物有多条通道，没有噪声，模型只能输出各通道的平均。

\[
b_0 = b_R + \sigma_b\,\varepsilon_b,\qquad X_0 = X_R + \sigma_x\,\varepsilon_x .
\]

训练采用条件流匹配：沿线性插值 \(z_t = (1-t)\,z_0 + t\,z_1\) 回归速度目标 \(z_1 - z_0\)（\(z\) 为 \(b\) 或 \(X\)），损失为掩码均方误差。噪声尺度 \(\sigma_b,\sigma_x\) 在验证集上分别为两臂挑选。

## 2.3 网络与对照臂 {#arms}

两臂共用同一个网络类，只靠“角色”区分，这样结果差异才能归因于“联合还是串联”。骨干为 6 层标量—向量消息传递（128 个标量通道、32 个向量通道），全连接图。

| 项目 | A 臂：串联 | B 臂：联合 |
|---|---|---|
| 网络 | 事件网络 g + 几何网络 h | 一个网络 f |
| 参数量 | 合计 960,498 | 935,970（相差 2.6%） |
| 训练 | g 学 \(b_0\to b_P\)；h 在真实 \(b_P\) 条件下学 \(X_0\to X_{TS}\) | f 同时学两个模态，共用同一个时间 t |
| 采样 | 先积分 g 并解码，再以 \(\hat b_P\) 为条件积分 h | 两个状态每一步同步积分，最后解码 |
| 每个候选的网络调用 | g 50 次 + h 50 次（每次约半个网络） | f 50 次 |

其余全部相同：数据、切分、批大小、步数、优化器、学习率表、EMA、种子、采样步数、候选数、解码器和评测代码。首轮正式训练两臂各有 2/3 个种子出现非有限损失；对 PaiNN 更新块做无参数预归一化后，挑选与 9 次正式训练全部重跑。

## 2.4 引导与五个效率臂（V1a） {#guidance}

V1a 把 H1 落到可检验的形式：**在生成尚未完成时，用当前几何的势垒相关分数施加干预，能否经由耦合生成器改变后续事件，并提高低势垒已知通道的发现效率。** 生成器改为两时钟训练（事件与几何可以各自推进），势垒头 \(h_E\)（只看事件）与 \(h_X\)（看几何）在 T1x 训练折内标签上训练。

方向规划中引导的基本形式：先估计终点，再沿势垒代理 \(\Phi\) 的梯度修正几何速度，

\[
\hat{x}_1 = x_t + (1 - t_x)\, v^x_\theta, \qquad v^x \leftarrow v^x - \lambda(t)\, \nabla_x \Phi(\hat{x}_1, \hat{b}_1).
\]

| 臂 | 生成方式 | 引导与搜索 | 用途 |
|---|---|---|---|
| A0 | 独立串联 g → h | 无引导，完成后统一评分 | 基础串联 |
| A1 | 独立串联 g → h | \(h_E\) 引导事件，随后固定事件生成几何 | 无 TS 几何的事件评分 |
| A2 | 强自适应串联 | 部分几何展开、\(h_X\) 排序、固定事件几何引导、晋级、重新提议 | **主对照** |
| B0 | 联合 | 无引导，完成后统一评分 | 共享检查点的无引导能力 |
| B1 | 联合 | 只对 x 施加 \(h_X\) 梯度，b 由耦合速度继续更新 | **主方法** |
| B2 | 事件轨迹回放 | x 接受同样干预，b 回放配对 B0 的完整轨迹 | 检查事件反馈的作用（不进效率排名） |

主比较固定为 B1 − A2：只胜过 A0 或 B0 不足以推进，因为 A2 已经能重新提议事件，并用同一评分器在固定事件下优化和分配几何搜索。

## 2.5 指标 {#metrics}

**M0 主指标 Hit@32。** 每个反应物采样 32 个候选；若至少一个候选同时满足（1）成键/断键集合与参考相同（允许一个反应物自同构），（2）同一自同构下 TS 的 Kabsch 对齐 RMSD（含氢）≤ 0.5 Å，则该反应 Hit = 1。先在母体内平均，再对母体平均；三个种子先在母体层面平均。次要指标（事件召回、合法率、命中 RMSD 中位数、不同事件数、Hit 随阈值 δ 的曲线）只报告、不决策。

**V1a 主终点：归一化 log-budget AUC。** 在 4、8、16、32、64 五个预算点上计算“最低已知参考通道”的联合召回（事件匹配且几何接近参考，`PROXY_MATCH`），按对数预算求曲线下面积，使每个预算倍增区间权重相同。预算单位是“B0 等效候选”，按冻结的执行顺序累计网络前向与反向调用，不受批处理效率影响。

**V1a 机制量。** 在同一起点上比较评分方向的推动 \(F_S\) 与不推 \(F_0\)、随机方向 \(F_R\)：

\[
M_0 = \mathbb{E}\,[\,U(F_S) - U(F_0)\,],\qquad M_R = \mathbb{E}\,[\,U(F_S) - U(F_R)\,],
\]

两项下界都大于 0 才算机制通过（v2.1 修订：v2.0 的逐对取最大值会系统性偏负）。

## 2.6 统计与预注册判据 {#criteria}

所有区间都是**按母体配对的 bootstrap**（两臂用同一组重采样母体），M0 重采样 10,000 次，取 95% 百分位区间。

**M0 判据**（Δ = M_B − M_A）：

| 结论 | 条件 | 预写的后续动作 |
|---|---|---|
| 去（GO） | 区间下限 > 0；3 个种子中至少 2 个 Δ > 0；合法率差的区间下限 > −0.02 | 进入 M1 |
| 不去（NO-GO） | 上限 < 0.02，或点估计 ≤ 0 | 放弃联合卖点，转向水相数据集；结果作为负结果保留 |
| 不确定 | 其他 | 最多延长 4 天，加种子、N 提到 64 |

M0 实际判 NO-GO 后，负责人保留联合生成作为架构前提，预写的“转向”没有执行（见 [3.1 节](results.md#m0)）。

**V1a 判据**：主比较与两个机制量的单侧 95% 下界都大于 0 判 `GO_V1b`；另有 `HOLD_DATA`、`HOLD_BASELINE`、`HOLD_SCORE`、`HOLD_POWER`、`NO_GO_RESOURCE_SMALL`、`NO_GO_MECHANISM_SMALL`、`NO_GO_WINDOW_THIS_CONFIG`、`HOLD_INCONCLUSIVE` 等预设出口。正式集规模由功效计划按预设规则冻结为 342 个母体（目标情形联合 GO 功效约 0.81）。

**V1b 判据**：只依赖认证后的差值 \(\Delta^{cert}\)。

| 状态 | 条件 |
|---|---|
| `V1A_CONFIRMED` | 计划内认证完成，\(\Delta^{cert}\) 单侧 95% 下界 > 0 |
| `V1A_OVERTURNED` | 计划内认证完成，单侧 95% 上界 ≤ 0 |
| `V1B_INCONCLUSIVE` | 计划内认证完成，区间跨 0 |
| `INCOMPLETE_BOUNDS` | 影响主决策的参考或候选仍未解决 |

## 2.7 DFT 认证链（V1b） {#certification}

V1a 的命中只是与 T1x 参考记录接近。V1b 用概率抽样加完整的量化认证链，检验代理误差是否会推翻 V1a 的结论：

| 任务 | 目的 | 交付物 |
|---|---|---|
| D0 | 冻结源总体、抽样方案和计算语义 | manifest、候选层与母体层总体表 |
| D1 | 用 6–10 条开发链实测完整认证链 | 成本与兼容性报告 |
| D2 | 参考锚点与指定参考 TS 认证 | 独立的精修参考表 |
| D3 | 阶段 A：候选分层审计 | 加权一阶鞍点率、严格 PPV、未匹配层严格产率 |
| D4 | 阶段 B：V1a 主终点认证 | \(\Delta^{cert}\)、修正量、决策 |
| D5 | 固定口径汇总与验收 | 报告、原始证据、实际成本 |

每条链包括：TS 优化与最终 Hessian（要求单个虚频且为反应模）、从同一 TS 双向 IRC、两侧端点优化与频率、端点身份与实际事件判定。指导原模板用 ORCA 6.1；n2 没有可用的量化 ORCA，负责人选择改用 gpu4pyscf + geomeTRIC（RKS ωB97X/6-31G(d)，解析 Hessian，几何阈值对齐 ORCA TightOpt）。D1 期间协议统一修订过多次，当前为 `v1b-h-gpu4pyscf-3`。

## 2.8 计算资源 {#compute}

GPU 计算在集群节点 n2（4 × RTX PRO 6000 Blackwell，96 GiB）上经 Slurm 提交。参考开销：M0 单次 60k 步训练约 0.45 GPU·h，修复后整轮约 5.6 GPU·h；V1b D1 约 6.1 + 0.6 GPU·h；开放世界 DFT 剩余 28 项预计约 11 GPU·h。原始输出留在 n2，仓库只提交报告、结果 JSON 和哈希（见[数据与证据](../data.md)）。
